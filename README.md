# BucpTSF: Breaking the Uniform Computation Paradigm in Time-Series Forecasting

**NeurIPS 2026 | Official Project Repository**

This repository accompanies our NeurIPS 2026 paper, *BucpTSF: Breaking the Uniform Computation Paradigm in Time-Series Forecasting*.

## Overview

BucpTSF is an information-density-driven structured framework for time-series forecasting. It coordinates three complementary components: temporal representation reorganization, frequency-selective structured token interaction, and horizon-conditioned structured extrapolation.
